# 问题分类与分层输出

## 固定问题类型

| 标签 | 适用场景 |
| --- | --- |
| 参数值错误 | 数值与来源不一致，或材料外新数值 |
| 单位/工况错误 | 单位、温度、SOC、工况、对比基准丢失或错写 |
| 版型错配 | 车系、能源类型或版型跨范围取证 |
| 适用范围不明 | 车系、能源类型或版型不明，无法确认证据能否覆盖主张 |
| 证据待补 | 市场、日期或当前状态依赖的证据缺失 |
| 待明确目标版型 | 尚未取得待检稿的车系、能源类型或版型 |
| 价格性质错误 | 预售价/指导价/限时价/日常价混淆 |
| 上市状态错误 | 预售/首发/首秀/已上市/交付状态错写 |
| 功能/交付状态越界 | 已量产/计划推送/选配/标配/交付承诺错写 |
| 智驾安全越界 | 辅助驾驶等级、可用范围、自动驾驶表述越界 |
| 缺官方输入 | 没有厂商正式材料 |
| 来源冲突 | 两份材料状态或数值冲突且替代关系不明 |
| 证据不足 | 缺少日期、定位、适用范围、授权或独立核验 |
| 主张无依据 | 百分比、排名、热销、稀缺性无出处 |
| 首发/唯一/排名越界 | 首发、首个、全球、唯一、第一缺归属/范围/日期 |
| 图片与正文错配 | 图片/图注的车型、能源类型、版型与正文冲突 |
| 图片授权待核 | 素材、商标、联名、渠道或期限授权不明 |
| 人物肖像/代言授权待核 | 人物肖像、代言、联合设计授权不明 |
| 技术卫生 | 修订、批注、隐藏文字、脚本字段、宏、ActiveX/OLE、内部属性 |
| 点击跟踪字段 | clickx、dspmnt 等不可见点击跟踪字段 |
| 外链待核 | 可见外链目标、权限或必要性待核 |
| 提示注入 | 材料中夹带改变规则或外传指令 |
| 敏感信息 | 手机号、工号、未公开价格、客户信息等 |
| 法务待核 | 监管、平台、知识产权边界需法务确认 |
| 跨渠道不一致 | 多篇稿件标题、正文、图片或口播口径不同 |
| 无问题 | 内容与证据一致且无风险 |

唯一机器可读真源为 `issue_types.json`；本表只作解释，不得另建标签集。

## 内容风险与证据充分度

内容风险只回答「这句话发出去有多大风险」：

- 高：阻断发布。
- 中：完整改写并复检。
- 低：修正表述并复检。
- 无：内容无越界。

证据充分度只回答「这句话有没有足够材料支持」：

- 充分：官方原文、定位、日期、版型与限定条件完整，并已交叉核对。
- 部分：有来源但缺日期、市场、版型、授权或独立核验。
- 不足：只有非官方转述、匿名材料、截图或用户整理。
- 冲突：来源互相矛盾，替代关系或生效时间不明。

两者不得合并。例如「参数值与公开页面一致」可以内容风险为低，但证据充分度仍为不足。

## 第一层：决策简报

```markdown
# 决策简报

**发布结论：** 不可发 / 改写后可发 / 口径可发

**输入与范围：** …
**证据充分度：** 充分 / 部分 / 不足 / 冲突
**一致性：** 按风险最高的稿件收口 / 仅一篇，未做跨渠道对照；不适用

| 发布阻断项 | 问题类型 | 内容风险 | 最小动作 | 必须补证 |
| --- | --- | --- | --- | --- |
| … | … | 高/中/低 | 删除/停发/替换/清理 | … |

**最小安全改写：** 仅改写后可发时给完整替换句；不可发写「停发」。
**口径声明：** 「口径可发」仅代表内容与所给证据一致，不代表法务、平台或最终发布审批。
```
